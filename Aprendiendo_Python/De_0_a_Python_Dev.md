## Recomendaciones
Lo ideal es que por lo mucho se tome máximo dos recursos para hacer en un inicio, pues hacerlos todos solo llevaría a gastar tiempo, para este caso, se utilizarán tanto el recurso de **CISCO** como el de **RoadMap** , ya que el primero da una certificación y el segundo nos dará la guía de aprendizaje, no obstante algunos ejercicios se obtendrán directamente de los repos de **Ejercicios y GitHub** .
